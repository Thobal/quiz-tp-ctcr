Stockage local des statistiques

Vos statistiques (scores, progression, historique des sessions) sont automatiquement sauvegardées dans la mémoire locale de votre navigateur. On appelle cela le "stockage local" ou localStorage. Aucune information n'est envoyée sur internet et aucun compte utilisateur n'est nécessaire.

Pour que vos statistiques soient conservées entre chaque utilisation, l'application doit toujours être accédée depuis le même endroit. Voici les trois cas de figure possibles :

Cas 1 — Fichier enregistré en local sur votre appareil
Enregistrez le fichier HTML sur votre appareil (ordinateur, tablette ou téléphone), puis ouvrez-le toujours depuis le même emplacement. Vos statistiques seront parfaitement conservées d'une session à l'autre, tant que vous ouvrez toujours le même fichier depuis le même dossier.

Cas 2 — Lien internet (URL)
Si quelqu'un vous a communiqué un lien internet vers cette application, accédez-y toujours via ce même lien. Vos statistiques seront conservées dans votre navigateur, associées à cette adresse. Ce mode fonctionne parfaitement, à condition d'utiliser toujours le même navigateur.

Cas 3 — Pièce jointe d'un email
Si vous avez reçu le fichier HTML de cette application par email, ne cliquez pas directement sur la pièce jointe pour l'ouvrir. Les navigateurs ouvrent alors le fichier depuis un dossier temporaire dont le nom change à chaque ouverture. L'application fonctionnera normalement — vous pourrez répondre aux questions et naviguer dans toutes les sections — mais vos statistiques seront perdues à chaque fois que vous fermerez le fichier. Pour conserver votre progression, enregistrez d'abord le fichier sur votre appareil, puis ouvrez-le depuis cet endroit à chaque utilisation (voir Cas 1).

Quelques précisions supplémentaires :

  • Chaque navigateur possède son propre stockage local. Si vous utilisez Chrome un jour et Safari un autre jour, vos statistiques ne seront pas partagées entre les deux.
  • Si vous videz le cache ou les données de navigation de votre navigateur, vos statistiques seront effacées.
  • La capacité de stockage disponible est d'environ 5 Mo, ce qui est largement suffisant pour des années d'utilisation de cette application.
